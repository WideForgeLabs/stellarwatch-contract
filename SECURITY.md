# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in StellarWatch contracts, please report it responsibly.

Do not open a public issue.

Instead, email the maintainers directly:

- Ikechukwu-Patrick: patrickikechukwukalukalu@gmail.com

Include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will respond within 48 hours and work with you to resolve the issue.

## Scope

This policy covers the smart contracts in this repository:

- contract-registry
- health-registry
- alert-rules

## Audit Status

These contracts have not been audited. Use at your own risk.

## Responsible Disclosure

We ask that you:

- Give us reasonable time to fix the issue before public disclosure
- Do not exploit the vulnerability for personal gain
- Do not access or modify data that does not belong to you
